JSF FASHION WEAR — WEBSITE PROJECT
=================================

ফাইল:
1. index.html — ওয়েবসাইটের মূল পেজ
2. style.css — Black & Premium Gold ডিজাইন
3. app.js — পণ্য, সার্চ, ক্যাটাগরি, কার্ট, চেকআউট ও ডেমো অ্যাডমিন
4. README-BN.txt — এই নির্দেশনা

চালু করার নিয়ম:
- ZIP Extract করুন।
- index.html ফাইল Chrome বা অন্য browser-এ খুলুন।
- ভালোভাবে চালাতে VS Code-এর Live Server ব্যবহার করতে পারেন।

ডেমো অ্যাডমিন:
- Admin বাটনে চাপুন।
- Demo password: JSF2026
- পণ্য যোগ/মুছে ফেলা এই ব্রাউজারের Local Storage-এ থাকবে।

গুরুত্বপূর্ণ:
এটি Frontend Demo Website। বাস্তব অনলাইন অর্ডার, একাধিক ডিভাইসে পণ্য sync,
অ্যাডমিনের নিরাপদ login, payment এবং order management চালু করতে Firebase
বা অন্য secure backend যুক্ত করতে হবে। শুধু frontend password নিরাপদ নয়।

নিজের পণ্য বসাতে app.js-এর DEFAULT_PRODUCTS তালিকা পরিবর্তন করুন।
ছবির URL হিসেবে নিজের আপলোড করা image URL ব্যবহার করতে পারবেন।
